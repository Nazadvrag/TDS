Библиотека включает в себя класс TDS - Tridiagonal System для хранения трёхдиагональных СЛАУ и методы их решения с использованием многопоточности через OpenMP:
1. Разбиение на блоки
2. Редукция
3. Метод Томаса (на одном потоке)
Заголовочный файл TDS.h содержит объявления классов:

SolvingMethod — абстрактный базовый класс для всех методов решения.

ThomasMethod — реализация метода Томаса.

PartitionMethod — реализация метода разделения.

ReductionMethod — реализация метода циклической редукции.

TDS — основной класс для хранения коэффициентов и вызова метода решения.

Файл реализации TDS.cpp содержит определения методов классов.

Класс SolvingMethod - абстрактный класс, определяющий интерфейс для всех методов решения.
Все методы наследуются от SolvingMethod и переопределяют виртуальную функцию:

double solve(double* a, double* b, double* c, double* f, int n, int num_threads, double*& x);

Параметры:

a, b, c, f – массивы коэффициентов (размер n). Внимание: алгоритмы модифицируют эти массивы.

n – размер системы.

num_threads – количество потоков для OpenMP (для ThomasMethod игнорируется).

x – ссылка на указатель, в который будет записан адрес массива-решения.

Возвращает время решения в секундах.

ThomasMethod - последовательная прогонка. Модифицирует входные массивы, после выполнения b[i] = 1, c и f содержат прогоночные коэффициенты.

PartitionMethod - параллельный метод на основе разбиения на блоки. Требует num_threads <= n.

ReductionMethod - параллельная циклическая редукция. Предполагает, что n+1 является степенью двойки (например, 1, 3, 7, 15, ...). Для других размеров поведение не определено.

Класс TDS хранит массивы коэффициентов a, b, c, f и указатель на выбранный метод решения.

Конструкторы:

TDS();   // размер = 1, массивы выделены, но не заполнены

TDS(double* _a, double* _b, double* _c, double* _f, int n); // копирует данные из инициализированных массивов

TDS(const TDS& other); // копирует данные из инициализированного объекта класса

Деструктор:

~TDS();

Операторы:

TDS& operator=(const TDS& other); //копирует данные в инициализированный объект из другого инициализированного объекта

Методы:

void setSize(int newSize);               // изменение размера (старые данные теряются)

int getSize();                            // текущий размер

void setMethod(SolvingMethod* newMethod); // установка метода (должен быть создан через new)

// Заполнение тестовыми данными (возвращают указатель на точное решение)

double* randomFill(int range);            // случайные коэффициенты в заданном диапазоне, известное решение

double* testFill();                        // простое решение: все x[i] = 1

double* testFill2();                        // решение с чередованием 2 и 1

// Решение системы

double solve(int num_threads, double*& x); // принимает кол-во поток и массив x, который заполняется решением, возвращает время (сек).
